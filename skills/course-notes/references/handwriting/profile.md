# Handwriting profile

One profile per student. It starts empty; fill it from the student's samples and
their lecture pages, and update it whenever they send a new sample or correct a
reading. Read it, and look at the sample sheets, before transcribing.

## Samples

Ask for these once, at the start of the course. Each is a photo of one page,
saved here.

| File                     | What it shows                                                      | Status                                       |
| ------------------------ | ------------------------------------------------------------------ | -------------------------------------------- |
| `alphabet.jpg`           | lowercase and uppercase alphabet, written at normal speed          | ask for it                                   |
| `digits-symbols.jpg`     | `0–9`, operators, brackets, Greek letters, the student's shorthand | ask before the first math-heavy lecture      |
| a normal-speed paragraph | letters as they look joined and fast                               | optional; real lecture pages serve meanwhile |

## Observations

Write one line per pattern, and say which sample or page showed it.

**Letters that collide.** Check these pairs in every hand: `l`/`I`/`1`/`|`,
`O`/`0`/`o`, `g`/`q`/`p`, `u`/`v`, `m`/`rn`, `cl`/`d`, `a`/`o`, `n`/`h`,
`5`/`S`, `2`/`z`. Note whether capitals are distinct shapes or larger lowercase,
since that decides whether case can be read.

**Distinctive letters.** The ones that are rarely misread and can anchor a
doubtful word.

**Habits.** Abbreviations (`diff`, `attn`, `w/`, `+` for "and"), how terms are
marked when introduced (underline, circle, box), how lines are grouped
(brackets, margin labels), whether slide figures get redrawn, how the lecturer's
own questions are marked (quotes).

## Corrections

Each reading the student corrected, and the pattern it taught:
`p2 L5 "Enc-End" → "Enc-Enc": final d and cl look alike`.
