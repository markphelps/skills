  2. 0.5 and 0.5: e0 = 1 for both, and each is divided by the total, 2. Equal scores always get equal weights. (0.5)

  4. Score each key against the query (dot product, divided by √dk); softmax the six scores into weights that sum to 1; average the six value vectors with those weights. (1.3; slide 62)
  5. Dot products of random vectors have variance dk; large scores make softmax nearly one-hot with tiny gradients. Dividing by √dk restores variance 1. (1.3; Vaswani §3.2.1)
  6. So a token can be found by one property (its key) and contribute another (its value). Both are learned projections, WK and WV. (1.3; slide 100)
  7. One complete attention computation. Each head owns its WQ, WK, WV; WO after the concatenation is shared. (1.4; Vaswani §3.2.2)
  8. dk = 512 / 8 = 64. Eight heads of width 64 have the same total width as one head of width 512, so the matrices have the same number of entries: 1,048,576 per layer either way. (1.4; check script)
  9. Queries from the decoder; keys and values from the encoder's output. (1.5; Vaswani §3.2.3)
  10. Training feeds the whole correct sentence at once, so each position could otherwise see the word it must predict. At inference later tokens do not exist yet. (1.6; slide 75)
  11. It deletes the encoder and the cross-attention, and keeps the stack of masked self-attention and feed-forward layers. (1.7; L2 slides 18–21)

Dot product: multiply two vectors position by position and add up; large when they are alike (0.3).

Gradient: how much the loss changes when a weight changes a little; training steps against it (0.6).

Attention: a weighted average of value vectors, with weights from how well a query matches each key.

Causal (masked) attention: attention in which a position may only look at itself and earlier positions.

Cross-attention (encoder-decoder attention): queries from the decoder, keys and values from the encoder.

Decoder-only: a Transformer with no encoder; the architecture of GPT-style LLMs.

Head: one attention computation with its own WQ, WK, WV.

Inference: running a trained model to produce output; weights frozen, one token per pass.

KV cache: stored keys and values of earlier tokens, so each inference step computes only the new token's.

Key, query, value: three learned projections of every token: what it offers to be matched on, what it looks for, and what it contributes.

Matrix: a table of numbers; multiplying two computes a grid of dot products (0.4).

Positional encoding: a vector added to each token's embedding so attention can tell positions apart.

Softmax: turns scores into positive weights that sum to 1 (0.5).

Token: the unit text is cut into: a word, a character, or a subword.

Vector: an ordered list of numbers; a token's embedding is one (0.2).
